# Source material

Raw, unpublished inputs for site content — customer quotes, notes, and anything
else we may draw on later.

**Nothing in this folder renders.** Astro only builds from `src/pages/` and
`src/content/`, so files here are never part of a page, the sitemap, or the
build output. That is the point: it keeps raw material versioned and reviewable
without publishing it by accident.

To actually publish something from here, copy it into the relevant place —
`src/content/testimonials/` feeds the home page slider, for example — and confirm
the attribution and permission first.
